# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.0   | :white_check_mark: |

## Reporting a Vulnerability

Report vulnerabilities by submitting an issue on https://github.com/Uhm-why/caduceus

My goal is to remain transparent with everything related to Caduceus. I will look into the issue as soon as possible, but do not guarantee any specific timelines.
